Dual-Model Sanitation AI Architecture

This system uses a two-stage computer vision pipeline combining YOLOv8 Instance Segmentation for object extraction and YOLOv8 Fine-Grained Classification for cleanliness evaluation.

1

Input Image / Video Frame

Captures sanitation area (railway carriage, washbasin, toilet compartment, aisle).

2

YOLOv8 Segmentation

Detects & segments 13 target sanitation categories (washbasin, commode, dustbin, aisle, tap, wall, etc.).

3

Bounding Crop & Resize

Extracts localized bounding box crops with custom padding and normalizes to 224x224.

4

YOLOv8 Classifier

Evaluates extracted crops into 3 cleanliness levels: Good, Average, or Bad.
